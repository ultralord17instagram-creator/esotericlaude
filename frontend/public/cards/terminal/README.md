# Пиксельная колода для лендинга «Таро Терминал»

Сюда кладём пиксель-арт карты для `/lp/taro-terminal`. Отдельно от `public/cards/*.png`
(те используются продуктом `/tarot` и лендингом `taro-him`, их не трогаем).

## Как называть файлы

**Формат:** PNG.
**Имена — словами (слаг аркана), а не номерами.**

Правила имени файла (важно для nginx):
- только латиница в нижнем регистре,
- без пробелов и кириллицы (пробел → дефис),
- kebab-case.

**Лучший вариант — слаг из `deck.js` (поле `en`).** Тогда русское имя карты и ключевые
слова для тизера подтянутся автоматически, копирайт дописывать не нужно:

**Рубашка (обязательна, одна на колоду):** `back.png` — её показывает перемешивание и экран `draw`.

**Размер:** все карты одного размера и пропорции (стандарт Таро 2:3), напр. 300×450 px.
Прозрачный фон допустим. Единая палитра/рамка, чтобы карты смотрелись одной колодой.

## Если имена свои (не из таблицы)

Можно и произвольные латинские слаги (`raven.png`, `broken-tower.png` и т.п.).
Тогда русские имена/ключевые слова не подтянутся сами — при реализации заведём
маленький манифест `terminalDeck.js`, где для каждого файла пропишем `ru` и (опц.) ключевые слова.
