## 1. Что уже готово (не менять)

Продукт «Расклад Таро» — три сценария гадания: «Карта дня», «Три карты» (5 тем),
«Да / Нет». Вся механика, лимиты, роуты и вёрстка уже реализованы. Тексты сейчас —
**плейсхолдеры вида `[Карта дня · аркан 0] Текст-заготовка.`**. Твоя задача — заменить их
реальными текстами, сохранив структуру ключей.

**Файлы, которые ты редактируешь (и только их):**

```
frontend/app/content/tarot/texts/day.js     # 22 текста «Карта дня»

**Не трогай:** `spreads.js`, `index.js`, `api.js`, всё в `frontend/app/tarot/`, backend.

Ключ везде — **номер Старшего аркана 0–21**. Для «Трёх карт» дополнительно — `themeId`.

## 3. Общие правила тона и объёма

- **Язык:** русский. Обращение на «ты».
- **Тон:** тёплый, поддерживающий, образный, без эзотерического жаргона-«воды» и без
  запугивания. Карта — это зеркало и подсказка, а не приговор.
- **Никаких обещаний конкретики** (не «в среду позвонит бывший»), а смысл/энергия/совет.
- **Без markdown внутри строк** — обычный текст, одна-две мысли на абзац.
- **Кавычки:** если внутри текста нужны кавычки — используй «ёлочки», не `"` (чтобы не
  ломать JS-строку в одинарных кавычках). Апострофы избегай или экранируй.
- **Длина** (ориентир, не жёстко):
  - Карта дня: 2–4 предложения (~250–400 знаков).
  - Да/Нет: 2–3 предложения (~200–350 знаков) — поддержка к полюсу ответа.
  - Три карты · intro темы: 2–3 предложения, задаёт рамку темы.
  - Три карты · карта в теме: 3–5 предложений (~300–500 знаков).

## 4. Файл `texts/day.js` — «Карта дня» (22)

Сценарий: пользователь получает одну карту на сегодня — общий настрой/послание дня.
Текст пиши как «энергия дня» через образ аркана: на что обратить внимание, какой настрой.

**Замени** нынешний программный плейсхолдер на явный объект-литерал:

```js
export const DAY_TEXTS = {
  0: 'Сегодня день чистого листа. Шут зовёт довериться дороге и сделать шаг налегке…',
  1: '…',
  // ... все ключи 0..21 обязательны ...
  21: '…',
}
```

## 5. Файл `texts/yesno.js` — «Да / Нет» (22) + полюса в `deck.js`

Сценарий: пользователь задаёт вопрос «да/нет», вытягивает одну карту. Ответ **Да** или
**Нет** определяется полем `yesno` карты в `deck.js`; текст в `yesno.js` — **поддерживающее
пояснение к этому ответу через образ аркана** (почему карта клонит к «да»/«нет», как это
прожить). Текст вопрос пользователя не знает — пиши универсально.

**Два под-задания:**

**5.1. Полюса в `deck.js`.** У каждого аркана уже стоит провизорный `yesno: 'yes'|'no'`.
Пройди по всем 22 и выставь осмысленный полюс (светлые/благоприятные арканы → `'yes'`,
тяжёлые/предостерегающие → `'no'`). Меняй **только значение `yesno`**, остальное не трогай.

**5.2. Тексты.** Замени плейсхолдер на явный литерал; тон текста должен **соответствовать
полюсу** карты из `deck.js`:

```js
export const YESNO_TEXTS = {
  0: 'Карты склоняются к «да»…',   // согласуй с DECK[0].yesno
  // ... 0..21 ...
}
```

## 6. Файл `texts/three.js` — «Три карты» (5 тем × (intro + 22))

Модель текста: **цельный текст на пару «тема + карта»**. Важное правило — **текст НЕ зависит
от позиции** (Прошлое/Настоящее/Будущее); позиция это лишь структурный подзаголовок в UI.
То есть для темы `ppf` карта «Смерть» имеет ОДИН текст, который одинаково подходит и как
«прошлое», и как «будущее». Пиши смысл карты В КОНТЕКСТЕ ТЕМЫ, без привязки ко времени.

`intro` — вводный абзац темы: 2–3 предложения, настраивают на тему до раскрытия карт.

**Пять тем (`themeId` → смысл, задающий ракурс всех 22 текстов):**

| themeId | Название | Ракурс текстов |
|---|---|---|
| `ppf` | Прошлое, Настоящее, Будущее | универсальный жизненный расклад, общий поток |
| `shadow` | Теневая сторона | вытесненное, внутренние тени, что не признаём в себе |
| `purpose` | Предназначение | призвание, смысл, куда ведёт путь |
| `partner` | Идеальный партнёр | отношения, каким людям/связям открыться |
| `ancestral` | Проклятие рода | родовые сценарии — **мягкий, бережный, исцеляющий тон, БЕЗ запугивания**; про освобождение и ресурс, а не про «порчу» |

**Структура файла** (замени плейсхолдеры; все 5 тем, у каждой intro + все 22 карты):

```js
export const THREE_TEXTS = {
  ppf: {
    intro: '…вводный абзац темы…',
    cards: { 0: '…', 1: '…', /* ... */ 21: '…' },
  },
  shadow:    { intro: '…', cards: { 0: '…', /* ...21 */ } },
  purpose:   { intro: '…', cards: { 0: '…', /* ...21 */ } },
  partner:   { intro: '…', cards: { 0: '…', /* ...21 */ } },
  ancestral: { intro: '…', cards: { 0: '…', /* ...21 */ } },  // мягкий тон
}
```

> Тема `ancestral` («Проклятие рода») — самая чувствительная. Тон строго поддерживающий:
> род как ресурс, паттерны как то, что можно осознать и отпустить. Никакого фатализма.
