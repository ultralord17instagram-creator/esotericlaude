# Лендинг «Скрытый дар» (предназначение) — дизайн-документ

Дата: 2026-07-23
Slug: `/lp/dar` · Бренд: «Скрытый дар» · Движок: матрица судьбы (`calculateMatrix`)

## Идея

Лендинг на тему «Предназначение», поданную через ведущий угол **скрытого дара**:
«В тебе есть сила, которую ты не включил». Мягкая боль (не «ты неудачник», а
«ты способна на большее, и что-то в тебе так и не вышло наружу») вскрывает
узнавание и тянет узнать, *что именно* за дар.

Продукт под капотом — Матрица судьбы. Точка чтения — **личное предназначение**.
Голос — женский, на «ты», тёплый, доверительный (как в `rod`). Без длинного тире.

Концовка по общему правилу проекта: лендинг заканчивается кнопкой «Узнать» →
регистрация основного сайта, дальше всплывает Paywall. На самом лендинге про
деньги/подписку не пишем.

## Драматургия (позвоночник)

Крючок на входе — «скрытый дар». Раскрытие нарастающими слоями по триаде матрицы:

| Слой | Блок | Что говорим | Матрица |
|---|---|---|---|
| 1 | Твой дар | «Вот что тебе дано от рождения, вот твоя настоящая сила» | Личное предназначение |
| 2 | Почему он спит | «Вот что глушит его, поэтому ты его в себе не замечаешь» | связка/боль |
| 3 | Где он оживает | «Вот твоё дело и место, где дар приносит отдачу» | Социальное предназначение |
| 4 | Зачем он дан | «Вот задача, ради которой этот дар в тебе» | Духовное предназначение |
| 5 | Первый шаг | «Вот с чего начать, чтобы включить его» (окно роста) | действие |

Слои 1–2 открыты (даём узнавание бесплатно), слои 3–5 под замком.

## Движок чтения — вариант A (22 уникальных дара по аркану)

Максимальная персональность: число предназначения сводится к аркану 1..22, и
для каждого аркана — своя проза. (Отвергнуты: вариант B — ~6 архетипов с
механикой rod «второй слой», и вариант C — фиксированная триада без ветвлений.)

Точка чтения в матрице: **`purposes.personal.adult`** —
`reduce(top_left + bot_right)` (центральная точка предназначения, метод Ладини).
Уже вычисляется в `content/matrix.js`, диапазон 1..22.

Число берётся **только из даты рождения** — детерминировано, SSR = клиент.
Ответы квиза на само чтение не влияют (нужны для вовлечения и, по желанию,
лёгкого «эха» в опенере).

## Пример текста (эталон) — Аркан 1 «Маг» (дар слова и воли)

**В чём твой дар.** Твой дар в том, чтобы словом и волей превращать замысел в
дело. Там, где другие годами собираются с духом, ты можешь просто взять и
начать: сказать, повести, сдвинуть. Люди рядом невольно слушают и идут за
тобой, даже когда ты сама этого не замечаешь. В тебе с рождения записана сила
первого шага, та, что двигает не только тебя.

**Почему ты им до сих пор не пользуешься.** Ты почти не включаешь эту силу,
потому что тебя приучили быть удобной и не высовываться. Свою яркость ты
привыкла приглушать, чтобы не показаться слишком громкой и слишком заметной.
Поэтому дар лежит внутри как сжатая пружина: ты чувствуешь, что способна на
большее, но раз за разом делаешь себя тише, чем ты есть.

**Где твой дар оживает: дело и достаток.** 🔒 Твоя сила оживает там, где ты
ведёшь и создаёшь своё, а не обслуживаешь чужое. Это дело, где твоё слово
решает. Пока ты на вторых ролях, поток проходит мимо, и деньги идут не к тебе.
Матрица показывает, в какой именно сфере твой дар начинает кормить.

**Зачем этот дар дан именно тебе.** 🔒 Он дан тебе не просто так. Твоя задача в
том, чтобы своим примером разрешать другим начинать: рядом с тобой люди впервые
решаются на то, чего боялись. Ты здесь, чтобы зажигать, и пока ты прячешь себя,
этот свет не доходит до тех, кому он предназначен.

**Первый шаг, чтобы включить его.** 🔒 Тебе нужен один шаг, которого ты
избегаешь дольше всего: заявить о себе вслух и взять ответственность там, где ты
давно могла. Матрица показывает, какой именно это шаг и до какого года открыто
твоё окно роста.

## Поток данных

```
квиз (эмоц. ответы + дата + имя)
  → calculateMatrix(birth_date)
  → arcana = purposes.personal.adult   // reduce(top_left + bot_right), 1..22
  → buildReveal(arcana, answers)        // из dar-copy.js
  → 5 блоков: 2 открытых (gift, whyAsleep) + 3 под замком (realization, mission, firstStep)
```

## Логика reveal (`dar-copy.js`)

```js
export const revealFields = [
  { id: 'gift',        label: 'В чём твой дар',                         locked: false },
  { id: 'whyAsleep',   label: 'Почему ты им до сих пор не пользуешься', locked: false },
  { id: 'realization', label: 'Где твой дар оживает: дело и достаток',  locked: true  },
  { id: 'mission',     label: 'Зачем этот дар дан именно тебе',         locked: true  },
  { id: 'firstStep',   label: 'Первый шаг, чтобы включить его',         locked: true  },
]

export const DAR_PACK = {
  1: { gift, whyAsleep, realization, mission, firstStep }, // Аркан 1 «Маг» — эталон
  // 2..22 — TODO, заполняются в отдельном чате
}

export function buildReveal(arcana, answers) {
  const d = DAR_PACK[arcana] || DAR_PACK[1] // фолбэк, пока пак не полон
  return revealFields.map(f => ({ ...f, value: fill(d[f.id], { name: answers.name }) }))
}
```

Токены в тексте: `{name}` (имя из квиза). Возможен `{year}` для окна роста в
`firstStep` — детерминированный плейсхолдер без `Date` (как в `rod-copy`).

## Квиз (эмоциональный разгон, женский голос)

~6 шагов «на узнавание» вокруг скрытого дара, финал — дата + имя (типы шагов
`choice` / `date` / `text`, как в `rod`). Направление формулировок:
- «Часто чувствуешь, что способна на большее, чем живёшь сейчас?»
- «Тебе говорили, что ты слишком…?» (яркая / чувствительная / умная)
- «Где ты сильнее всего гасишь себя?»
- «Что мешает раскрыться?»
- дата рождения → имя.

Точные формулировки — в каркасе `dar.js`, тон как в `rod`.

## Концовка

Открытые 2 блока показываются сразу. 3 закрытых — карточки-тизеры с кнопкой
«Узнать» → `/register` (или `/lk`, если залогинен). Перед переходом
`localStorage['post_checkout_return'] = '/lp/dar'`. После оплаты и возврата
подписанного пользователя залоченные блоки открываются без повторного ввода
(сохранённый квиз в `loadQuiz(slug)`). Дисклеймер: «инструмент саморефлексии,
не медицинская/психологическая услуга». Про деньги/подписку на лендинге — молчок.
