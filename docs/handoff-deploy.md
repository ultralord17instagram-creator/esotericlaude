# Задача: выкатить сайт на основной домен

Ниже всё, что нужно поменять в коде и конфигах перед деплоем. Пути даны от
корня репозитория.

Реквизиты ИП, тексты документов, тарифы и подвал уже сделаны и захардкожены
не по файлам, а в двух конфигурационных модулях. Переписывать документы не
нужно, нужно только подставить значения из списка ниже.

---

## 1. Домен

### `nginx/prod.conf`

Заменить `YOUR_DOMAIN` на реальный домен в четырёх местах:

- строка 23: `server_name` HTTP-блока
- строка 40: `server_name` HTTPS-блока
- строка 45: путь к `fullchain.pem`
- строка 46: путь к `privkey.pem`

Пути к сертификатам должны совпадать с доменом, переданным в certbot.

### SSL

```bash
./scripts/ssl_init.sh ДОМЕН admin@ПОЧТА
```

Запускать, когда DNS уже указывает на сервер и nginx поднят на 80 порту.

### `.env` в корне (создать из `.env.example`)

```
NEXT_PUBLIC_SITE_URL=https://ДОМЕН     # с протоколом, без слэша на конце
DATABASE_URL=...
AUTH_SERVICE_URL=...
AUTH_SERVICE_API_KEY=...
OFFER_ID=...
PAYMENT_SERVICE_URL=...
PAY_FORM_URL=...
NEXT_PUBLIC_YANDEX_VERIFICATION=       # см. п.4
NEXT_PUBLIC_GOOGLE_VERIFICATION=       # см. п.4
DEBUG=false
```

`DEBUG=false` обязателен: при `true` наружу открыт `/docs` со схемой API.

### `frontend/.env`

```
NEXT_PUBLIC_OFFER_ID=...
NEXT_PUBLIC_PAYMENT_BACK_URL=https://ДОМЕН/lk
NEXT_PUBLIC_CP_PUBLIC_ID=...           # Public ID из кабинета CloudPayments
PS_URL=...
PS_API_KEY=...
TS_URL=...
TS_API_KEY=...
ADMIN_PASSWORD=...                     # пароль для /admin
```

`BACKEND_URL` не задавать: в проде его выставляет `docker-compose.prod.yml`
как `http://backend:8000`.

### ВАЖНО про пересборку

`NEXT_PUBLIC_SITE_URL` и коды вебмастеров это `NEXT_PUBLIC_*` переменные. Они
вшиваются в бандл **на сборке**, задать их в рантайме недостаточно.

Из `SITE_URL` строятся не только canonical и sitemap, но и адреса внутри
юридических документов: ссылки на оферту и политику, адрес сайта в тексте
оферты и в форме согласия. Не пересоберёте фронт после смены домена, и в
договоре останется заглушка `astrix.ru`.

```bash
docker compose -f docker-compose.prod.yml build frontend
```

### `scripts/deploy.sh`

Скрипт делает `git pull origin main`. Основная ветка репозитория `master`,
актуальная работа в `feat/astrix-homepage-redesign`. Привести в соответствие:
либо влить в ветку, которую тянет скрипт, либо поправить строку в скрипте.

## 3. Тарифы

### `frontend/app/legal/tariffs.js`

Сейчас объявлено:

| Тариф | Цена | Период |
|---|---|---|
| Пробный | 7 ₽ | 7 дней |
| Основной | 299 ₽ | 7 дней |
| Особый | 99 ₽ | 2 дня |

Эти суммы напечатаны в публичной оферте, то есть являются публичным обещанием
цены. Сверить с тарифом, настроенным в кабинете партнёрки:

```bash
curl https://ДОМЕН/api/v1/subscriptions/tariff
```

`first_amount`, `first_days`, `amount`, `days` из ответа должны совпасть с
файлом. Не совпали, правится только `tariffs.js`: из него цену одновременно
берут оферта, условия предоставления услуг, страница `/tariff`, пейволл
(`frontend/app/components/ui/Paywall.jsx`) и кнопка оформления в личном
кабинете (`frontend/app/lk/LKClient.jsx`). В самих документах цифр руками нет.

После правки пересобрать фронт.

### Даты редакций

## 5. Что осталось незаконченным

### Форма отмены подписки `/cancel` это заглушка

`frontend/app/cancel/CancelClient.jsx`: форма валидирует поля и показывает
экран «Заявка принята», но никуда ничего не отправляет. Место для запроса
помечено `TODO` в `handleSubmit`.

Нужно подключить приём заявок (почта, телеграм-бот или эндпоинт бэкенда).
Вместе с этим:

1. Дописать первые 6 и последние 4 цифры карты в перечень обрабатываемых
   данных в `frontend/app/privacy/privacy.content.js`: раздел 6 (пункт
   «Персональные данные») и пункт 3 формы согласия. Сейчас их там нет, потому
   что мы их не собираем.
2. Убедиться, что цифры карты не попадают в логи.

До подключения страница обещает пользователю отмену в течение 24 часов,
которую физически никто не получит.

### Контакт поддержки

Во всех документах контакт один: почта из `operator.js`. Если у проекта
появится телеграм-канал поддержки, заменить в четырёх местах:

- `frontend/app/privacy/privacy.content.js` — пункты 8.4, 12.1 и пункт 9 формы согласия
- `frontend/app/offer/offer.content.js` — пункт 6.1
- `frontend/app/tariff/page.jsx` — блок «Отмена подписки»
- `frontend/app/cancel/CancelClient.jsx` — экран после отправки

### Подвал на лендингах

Общий подвал со ссылками на документы рендерится на всех страницах, кроме
`/lp/*`: у лендингов собственная самодостаточная вёрстка. Реализовано в
`frontend/app/components/Footer.jsx`. Если партнёрка или модерация рекламы
потребуют ссылки на документы и на лендингах, нужно будет добавить туда
отдельную компактную строку.
