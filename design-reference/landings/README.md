# Дизайны лендингов (партнёрская воронка)

Сюда складываются макеты **маркетинговых лендингов** под холодный трафик из
партнёрской сети. Это НЕ дизайн страниц самого сайта (те лежат в соседних
папках вида `*-reference/`), а отдельные посадочные под конкретный продукт.

## Как устроено

- Дизайн рисуется в **Claude Design**, экспортируется в `.dc.html`.
- Один продукт = одна подпапка (`matrix/`, `tarot/`, `numerology/`, `horoscope/`).
- Внутри продукта можно держать несколько экранов и вариаций под разные
  креативы/партнёров.

## Соглашение об именах файлов

Внутри `matrix/` (и аналогично для других продуктов):

```
matrix/
  01-hero.dc.html        # первый экран (заголовок + CTA "Пройти тест")
  02-quiz.dc.html        # экраны квиза (шаги/прогресс)
  03-teaser.dc.html      # частичный результат матрицы
  04-paywall.dc.html     # пейвол с оффером подписки
  variants/              # (опционально) вариации под конкретные креативы
    money.dc.html
```

Каждый лендинг может выглядеть **полностью иначе, чем основной сайт** и чем
другие лендинги: свои цвета, шрифты, фон, порядок блоков. Общей остаётся только
логика воронки (квиз → тизер → пейвол → оплата), не внешний вид.

Готовый макет отсюда разработчик переносит в рабочий лендинг на роуте
`/lp/<продукт>`. Подробности — в `docs/plans/2026-07-13-matrix-landing-design.md`.
