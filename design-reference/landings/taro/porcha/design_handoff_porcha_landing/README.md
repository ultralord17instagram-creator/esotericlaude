## Overview
Одностраничный квиз-лендинг «таро-диагностика на порчу/негатив». Пользователь проходит короткий тест, вводит имя и дату рождения, видит анимацию «тасования колоды», выбирает 3 карты и получает расшифровку расклада с призывом к платной консультации. Цель — вовлечь и подвести к CTA «Узнать».

## Screens / Views
Один компонент с машиной состояний. Экраны (state `screen`): `hero → quiz → name → loading → pick → result → summary`.

### 1. Hero (`hero`)
- **Назначение**: захват внимания, старт.
- **Layout (ПК)**: центрированный grid 2 колонки `1.05fr / .95fr`, gap 70px, контейнер `width:1120px; max-width:92vw`. Слева текст (лево-выравнивание), справа веер из 3 карт-рубашек. Мобайл — вертикально по центру внутри frame 390×844.
- **Компоненты**: надзаголовок (Cormorant italic 22px, `#c98088`); заголовок Playfair 74px (ПК)/40px (моб), «порча?» цветом `#e04455`; подзаголовок Manrope 19px `#a2898e`, max-width 440; кнопка `Пройти проверку` (Oswald 18px uppercase, красный градиент, padding 20×54, radius 9, shadow `0 14px 40px rgba(196,26,44,.4)`); подпись Cormorant italic 17px `#7a6065`.
- **Карты-рубашки**: 3 шт, центральная крупнее (164×278), боковые повёрнуты `rotateY(±20deg)`; фон `linear-gradient(180deg,#1d070a,#100406)`, рисунок рубашки — полумесяц (два круга: красный радиальный + перекрывающий тёмный) + ромбик-искра сверху. Плавный дрейф `slowDrift` 7s.

### 2. Проверка / квиз (`quiz`)
- **Назначение**: по одному утверждению — «узнаёшь в себе?».
- **Layout**: по центру. Сверху шкала «Плотность негатива» (width 520), ниже — «Знак N из 9» + заголовок `Узнаёшь это в себе?`, по центру карточка-утверждение (стопка из 3 со смещением/поворотом), под ней 2 кнопки, внизу — прогресс-тики (по числу вопросов).
- **Карточка**: 440×min320 (ПК), фон `linear-gradient(160deg,#220c11,#150709)`, border `1.5px rgba(224,68,85,.4)`, glow. Уголки-скобки в 4 углах, сверху разделитель (линия—ромбик-искра—линия), крупная кавычка `“` (Playfair 52px, `rgba(224,68,85,.6)`), текст утверждения Playfair italic 27px `#f4e9ea`, снизу орнамент из 3 ромбиков.
- **Кнопки**: `Мимо` (outline, `#b79ba0`, border `rgba(224,68,85,.3)`, flex:1) и `Это про меня` (красный градиент, flex:1.4).
- **Тики**: 9 полосок 20×3px; на «да» — `#e04455` + glow, на «нет» — `rgba(224,68,85,.3)`, непройденные — `rgba(224,68,85,.12)`.
- **Шкала «Плотность негатива»**: лейбл Oswald + процент; трек `#1c1114` h9, заливка `linear-gradient(90deg,#7a0d16,#e04455)` + glow, transition width .5s.

### 3. Имя + дата рождения (`name`)
- **Layout**: центр, контейнер 460px. Заголовок `Как тебя зовут?` (Playfair 44px), подзаголовок `Колода ляжет на твоё имя и дату.`, 2 поля (Имя — text; дата — `type=date`, `color-scheme:dark`), подсказка, кнопка `Разложить карты`.
- **Поля**: фон `linear-gradient(160deg,#180b0e,#0e0708)`, border `rgba(224,68,85,.28)`, radius 12, padding 18×20; focus — border `#e04455` + `0 0 0 3px rgba(224,68,85,.18)`.
- **Валидация**: кнопка активна только если имя непустое (`name.trim().length > 0`); иначе disabled-стиль.

### 4. Загрузка (`loading`)
- **Назначение**: «тасую колоду».
- **Layout**: центр. Анимация из 5 карт-рубашек, раскрывающихся веером и сходящихся (`fan` 1.9s, стагер delay 0/.12/.24/.36/.48s, transform-origin 50% 100%, per-card `--r`/`--y`), пульсирующее свечение за ними, весь блок парит `floaty` 5s. Ниже заголовок `Тасую колоду на тебя…` (Playfair), подпись `Проверяю, чужое это или своё…` (Cormorant italic), тонкая полоска прогресса (260×6).
- **Поведение**: `loadPct` идёт 0→100 (интервал 90мс, шаг +4, после 82% +2); по достижении 100% через 550мс авто-переход на `pick`.

### 5. Выбор трёх карт (`pick`)
- **Layout**: центр. Заголовок `Выбери три карты`, подзаголовок `Не думай. Тянись к тем, что зовут.`, ряд из 6 карт-рубашек (124×196, wrap), счётчик `Выбрано N из 3`, кнопка `Раскрыть карты`.
- **Поведение**: тап выбирает/снимает; максимум 3. Выбранная поднимается `translateY(-16px) scale(1.03)`, border `#e04455`, glow, в углу бейдж с порядковым номером (1/2/3). Кнопка активна только при 3 выбранных.

### 6. Результат (`result`)
- **Layout (ПК)**: центрированная колонка max-width 720. Заголовок `Три карты. Что на тебе, откуда и снимается ли.` по центру; ряд из 3 карт (aspect 2/3.3, max 180 каждая) с подписями под ними: `Что на тебе` / `Откуда это` / `Что дальше`; ниже 3 абзаца расшифровки; по центру кнопка `Итог расклада` + ссылка `Начать заново`. Экран скроллится (`overflow-y:auto`).
- **Карты**: раскрываются флипом `flipIn` (rotateY -85°→0), стагер delay .1 / .35 / .6s.
- **Текст**: печатается посимвольно (typewriter) с мигающим курсором `▍` (`blink` 1s). Жирные фрагменты — цвет `#f2e3e5`, weight 600; обычные — `#c9b9bd`, weight 400. Полный текст — см. раздел «Тексты результата» ниже.

### 7. Итог расклада (`summary`)
- **Layout**: центр, max-width 680, скролл. Надзаголовок `Итог расклада` (Oswald caps), крупный абзац Playfair 27px, строка `Карты показали направление. Дальше открывается:`, 3 буллета с ромбовидными маркерами, кнопка `Узнать`, ссылка `← пройти заново`.

## Interactions & Behavior
- **Навигация**: линейная машина состояний (см. выше). Кнопка «назад» (кружок со стрелкой) на экранах quiz/name.
- **Свайп-анимация карточки квиза**: при `Это про меня` карточка улетает вправо `translateX(150%) rotate(16deg)`, при `Мимо` — влево `translateX(-150%) rotate(-16deg)`, opacity→0, transition .38s `cubic-bezier(.5,.05,.4,1)`; через 380мс коммит ответа и следующая карточка въезжает. Клики заблокированы во время анимации (`flying`-lock).
- **Шкала негатива**: `percent = round(yesCount / 9 * 100)`, обновляется по мере ответов.
- **Загрузка**: авто-таймер (см. экран 4).
- **Результат**: флип карт + typewriter (старт через 950мс после входа, шаг +3 символа каждые 16мс).
- **Сброс**: `Начать заново` / `← пройти заново` очищает всё состояние и возвращает на `hero`.

## State Management
- `screen`: текущий экран (enum выше)
- `qIndex` (0…9), `yes` (кол-во «да»), `answers[]` (bool по вопросам)
- `flying`: `'left' | 'right' | null` — анимация ухода карточки
- `name`, `dob`: поля ввода
- `loadPct` (0…100): прогресс загрузки
- `picked[]`: индексы выбранных карт (max 3)
- `typed`: сколько символов расшифровки уже «напечатано»
- Таймеры: загрузка, typewriter, fly — очищать при unmount и restart.

## Тексты квиза (9 утверждений, порядок важен)
1. Силы уходят в никуда, просыпаешься уже уставшей
2. Деньги утекают сквозь пальцы, сколько бы ни было
3. Отношения рушатся на ровном месте
4. Любое дело упирается в стену перед самым концом
5. Тяжёлые сны и тревога без причины
6. Чувство, что кто-то желает тебе зла
7. Пошла чёрная полоса, всё валится из рук
8. Всё сломалось после одного человека или события
9. Смотришь в зеркало и себя не узнаёшь

## Тексты результата (жирное выделено **)
1. Открытой метки карты не дали, но и чистым расклад не назвали. **Первая карта — то, что ты носишь прямо сейчас.** Силы уходят, а радости нет — будто кто-то тихо отматывает их себе. Это давно не про обычную усталость, ты и сама это чувствуешь.
2. **Вторая карта — про источник.** Всё завязано на одном событии или человеке; с той точки полоса не кончается. Ты и сама помнишь этот момент — жизнь будто раскололась на «до» и «после». То, что пришло тогда, сидит на тебе до сих пор.
3. **Третья карта — про исход.** Снять это тебе по плечу, ресурс есть. Сейчас оно ловится в самом начале. Прозеваешь — окрепнет, и снимать придётся долго.
