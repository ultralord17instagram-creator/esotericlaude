# Handoff: Таро-лендинг «Расклад на него» (мобайл + ПК)

## Overview
Байт-воронка (bait funnel) для гадания на Таро «на него». Цель — довести
пользовательницу от ввода имени до кнопки покупки через персонализированный
саморазворачивающийся расклад, который обрывается на самом важном месте.
Один и тот же сценарий реализован в двух версиях: **мобильной** и **десктопной**.

Воронка из 6 состояний (единый стейт-машина `screen`):
1. **Имя** — ввод имени «его».
2. **Вопрос** — выбор одного из 4 вопросов.
3. **Настройка колоды** — экран «загрузки»/«думает» с анимацией тасования (авто-переход ~5.4 c).
4. **Выбор карт** — тап по 3 картам из колоды рубашками вверх.
5. **Расклад (ядро)** — 3 карты раскрываются по очереди 3D-флипом, толкования печатаются (typewriter), в конце — обрыв на пейволле.
6. **Твой ход** — финальная «загадочная» карта + байт-текст + кнопка.

Порядок переходов: 1 → 2 → 3 → 4 → 5 → 6. (Во внутренней нумерации `screen`
экран «Настройка колоды» имеет значение `2`, а «Вопрос» — `3`; переходы см. ниже.)

## About the Design Files
Файлы в этом бандле — **дизайн-референсы, созданные в HTML** (интерактивные
прототипы, показывающие внешний вид и поведение), а **не продакшн-код для
копирования**. Задача — **воссоздать эти экраны в среде целевого кодовой базы**
(React / Vue / SwiftUI / native и т.п.), используя её паттерны и библиотеки. Если
среды ещё нет — выбрать подходящий фреймворк и реализовать дизайн в нём.

Прототипы написаны в формате «Design Component» (`.dc.html`) и используют
рантайм `support.js` (React под капотом). Для продакшена рантайм не нужен —
переносите разметку/логику в компоненты своего стека. Логика (стейт-машина,
таймеры, typewriter) полностью в `<script>`-блоке каждого файла — используйте её
как эталон поведения.

## Fidelity
**High-fidelity (hifi).** Финальные цвета, типографика, отступы, анимации и копирайт.
Воссоздавать пиксельно, средствами существующей дизайн-системы кодовой базы.

## Design Tokens
Заданы как CSS-переменные на корне (и переиспользуются inline):
- `--ink` (основной текст): `#ece7f6`
- `--muted` (вторичный текст): `#a99ec6`
- `--line` (границы): `rgba(185,170,225,.24)`
- `--cream` (заливка primary-кнопок): `#f3eee4`, текст на ней `#1a0f2e`
- `--accent` (акцент, настраиваемый): `#8f6ff0` (альтернативы: `#b06fe0`, `#6f8ff0`, `#c76fa8`)
- Фон приложения: `radial-gradient(130% 100% at 50% -6%, #2c1b52 0%, #170e30 46%, #0c0720 100%)`
- Карта-рубашка (лицевая сторона рубашки): `linear-gradient(160deg,#efeaf7,#d3c8ea)` + inset-бордеры
- Мистическая карта (тёмная): `linear-gradient(160deg,#2c1b56,#140c2b)`, свечение `--accent`
- Свечение свечи (декор): `radial-gradient(circle, rgba(180,70,220,.4), transparent 62%)`, blur 34px

Типографика:
- Заголовки/акценты: **Playfair Display** (500/600, italic для акцентов), Google Fonts.
- UI/текст: **Manrope** (400/500/600/700), Google Fonts.
- Радиусы: поля/кнопки 15–16px, карты 10–22px, пилюли/бейджи 50%.
- Мобильные размеры: H1 25–26px, body 14.5px, кнопки 16px, подписи 10–12px.
- Десктоп размеры: H1 hero 42px, H1 экранов 34–40px, body 16–17px, кнопки 17px.

Анимации (keyframes, все ease-in-out если не указано):
- `riseUp` / `riseX` — появление с подъёмом/сдвигом (0.5–0.7s, stagger по задержке).
- `dealIn` — карточки-кнопки «въезжают» снизу.
- `sway` — медленное покачивание фонового веера (9–11s).
- `twinkle` — мерцание звёзд (3.6s).
- `screenIn` — вход экрана (0.5–0.6s).
- `fanShuffle` — тасование колоды на экране «Настройка» (2.8s, per-card `--a` угол + `animation-delay` stagger).
- `glowBreath` — пульс свечения под колодой.
- `flipIn` / 3D `rotateY` — раскрытие карт в раскладе (0.8s cubic-bezier(.3,.8,.25,1)).
- `glare` — блик при перевороте карты (1s).
- `glowPulse` — пульс свечения на primary-кнопках и мистической карте.
- `shimmer` — световая полоса по карте.
- `blink` — курсор typewriter (1s step-end).
- `floaty` — парение финальной карты; `shake` — «вздрагивание» карты при тапе (заперта).
- `auraSpin` — вращающееся коническое свечение вокруг мистической карты.

## Screens / Views

### 1. Имя (hero)
- **Purpose**: ввести имя «его» и начать.
- **Mobile layout**: вертикально по центру — логотип, надзаголовок «Расклад Таро на него», H1 «Введи его имя. Карты скажут о нём то, что ты чувствуешь, но не можешь проверить.», поле «Его имя», подпись «Достаточно имени — колода найдёт его энергию.», кнопка «Продолжить».
- **Desktop layout**: две колонки. Слева — надзаголовок, H1 «Введи его имя. Карты скажут о нём то, чего ты не можешь проверить.», подзаголовок, поле + кнопка «Продолжить» (в колонке max-width 440px), микрокопия. Справа — крупная парящая «мистическая» карта (250×392) с вращающейся аурой, полумесяцем, звездой, бликом.
- **Components**: поле ввода (h 56–62px, border `--line`, focus → border `--accent` + фон `rgba(143,111,240,.1)`); primary-кнопка (`--cream` фон, тёмный текст, hover — тень `--accent`, active — scale .98/.99).
- **Copy**: см. выше дословно.

### 2. Вопрос
- **Purpose**: выбрать один из 4 вопросов.
- **Copy заголовков**: надзаголовок «Расклад Таро на него», H1 «Выбери вопрос, который не даёт тебе спать.», подзаголовок «Колода ответит именно на него.»
- **4 варианта (дословно)**: «Вернётся ли он ко мне» · «Что он на самом деле ко мне чувствует» · «Что он от меня скрывает» · «Есть ли у него другая».
- **Mobile layout**: логотип, шаги-точки (3), заголовки, вертикальный список из 4 карточек-кнопок (min-height 58px, стрелка «→» справа). Появляются по очереди (`dealIn`, stagger).
- **Desktop layout**: центрированная колонка max-width 860px; шаги-точки; заголовки; **сетка 2×2** карточек-кнопок (min-height 86px, padding 20/24, radius 16). Hover — border `--accent` + мягкая тень; выбранная — заливка `--accent`, белый текст.
- **Поведение**: по клику кнопка подсвечивается (~500ms), затем переход к экрану «Настройка колоды».
- Есть кнопка «назад» (← в круге) → на экран «Имя».

### 3. Настройка колоды («думает»)
- **Purpose**: имитация персональной настройки перед раскладом; авто-переход.
- **Copy**: H1 «Настраиваю колоду на него…». Три строки, сменяющиеся кроссфейдом (~1.8s каждая):
  1. «{Имя} ещё не знает, что карты уже говорят о нём…» (если имя пустое — «Он …»)
  2. «Считываю, что он прячет за словами…»
  3. «Свожу его линию с твоей…»
- **Анимация**: колода из 5 карт-рубашек циклично собирается в стопку и раскрывается веером (`fanShuffle`, per-card угол `--a` = −26/−13/0/13/26deg, `animation-delay` 0/.08/.16/.24/.32s), под колодой — пульсирующее свечение (`glowBreath`), по центральной карте — блик (`shimmer`). НЕ обычный спиннер.
- **Тайминги**: строка2 на 1800ms, строка3 на 3600ms, авто-переход к «Выбор карт» на 5400ms.

### 4. Выбор карт
- **Copy**: надзаголовок «Твой вопрос», H1 = выбранный вопрос в «ёлочках», подзаголовок «Сосредоточься на нём и выбери **3 карты**. Колода уже знает ответ.»
- **Mobile layout**: логотип, шаги-точки, заголовки, сетка карт-рубашек (3 в ряд, всего 9), счётчик «Выбрано N из 3», кнопка «Раскрыть расклад» (появляется при 3 выбранных).
- **Desktop layout**: центрированная колонка max-width 900px; горизонтальный ряд из **7** карт (flex-wrap, карта 108px, aspect .64); счётчик; кнопка «Раскрыть расклад».
- **Поведение**: тап выбирает/снимает карту (максимум 3); выбранная — приподнимается (translateY −12/−14px), обводка `--accent`, бейдж с номером (1/2/3) в углу. При 3 выбранных — primary-кнопка (`glowPulse`).
- Кнопка «назад» → на экран «Вопрос».

### 5. Расклад — ядро (карты раскрываются)
- **Purpose**: показать 3 толкования и оборвать перед покупкой.
- **Copy**: надзаголовок «Твой расклад», H1 «Колода легла. Три карты открыты. Последняя ждёт тебя.»
- **Позиции карт (подписи)**: «Где он сейчас» · «Что внутри» · «Поворот».
- **Толкования (typewriter, по 2 предложения, дословно)**:
  1. «{Имя} не так спокоен без тебя, как хочет казаться. Ты всё ещё всплываешь у него в мыслях, даже когда он это отрицает.»
  2. «Его тянет к тебе сильнее, чем он готов признать, но гордость и страх снова проиграть держат его на расстоянии. Он ждёт от тебя знака и не получает его.»
  3. «Рядом легла карта, которую ты не захочешь видеть: ты рискуешь оказаться не единственной в его поле. Времени у тебя меньше, чем кажется.»
- **Mobile layout**: 3 карты в ряд сверху, под ними толкования появляются списком по очереди; экран мягко доскроливает к активной карте.
- **Desktop layout**: центрированная колонка max-width 760px; ряд из 3 больших карт (max 210px), под ним — 3 **колонки** толкований, выровненные под карты; толкование появляется в своей колонке.
- **Анимация (последовательность)**: карты «сдаются» из стопки (появление, stagger 0.14s) → по очереди переворачиваются 3D-флипом с бликом `glare` → под картой проявляется подпись позиции → толкование печатается посимвольно (интервал 26ms) с мигающим курсором; **следующая карта открывается только после допечатывания текущей**. Активная карта подсвечена `--accent`.
- **Финал**: после 3-го толкования показывается блок покупки — кнопка **«Узнай что делать»** (`glowPulse`) и ссылка «Начать заново».
- Кнопка «назад» → на экран «Выбор карт».

### 6. Твой ход (финал)
- **Триггер**: клик «Узнай что делать» → анимация загрузки (спиннер + «Открываем расклад…», ~2s) → этот экран.
- **Copy**: строка сверху «Три карты сказали, что происходит. **Эта говорит, что с этим делать.**»; заголовок на карте «Твой ход»; байт-текст «Карта называет одно действие, которое решает всё: сделаешь его в ближайшие дни, и {имя} сам потянется к тебе.»; кнопка **«Перевернуть карту»**; ссылка «Начать заново».
- **Mobile layout**: строка сверху, крупная загадочная карта по центру, байт-текст, кнопка.
- **Desktop layout**: две колонки — слева большая карта (272px), справа надзаголовок «Последняя карта», заголовок, байт-текст, кнопка.
- **Карта**: максимально «загадочная» — тёмная, парящая (`floaty`), вращающаяся аура (`auraSpin`), полумесяц + звезда, блик, свечение `glowPulse`. По тапу — «вздрагивает» (`shake`), т.к. заперта (здесь ведёт реальная покупка).
- Кнопка «назад» → на экран «Расклад».

## Interactions & Behavior
- Единый стейт `screen` (1..6) + переходы: `onNext1` (Имя→Вопрос), `onPickQ` (Вопрос→Настройка, затем авто→Выбор карт через таймеры `runTune`), `onCardTap` (тоггл выбора, max 3), `onContinue` (Выбор→Расклад, запуск `startReading`), `onBuy` (Расклад→спиннер→Твой ход через 2s), `onFlip` (shake финальной карты), `onRestart` (сброс к экрану 1).
- Расклад: `startReading` → `revealCard(i)` (флип) → `typeCard(i)` (typewriter, setInterval 26ms) → по завершении следующая карта или `finishReading` (показ пейволла + доскролл вниз).
- Персонализация именем: пустое имя → подстановка «Он/он».
- Все primary-кнопки: hover-тень, active scale .98; карточки-вопросы: hover-border + тень.
- Автоскролл к активной карте/пейволлу — плавный (`scrollTo behavior:smooth`), НЕ `scrollIntoView`.

## State Management
Переменные состояния:
- `screen` (1..6) — текущий экран.
- `name` — имя «его» (строка).
- `question` / `selecting` — выбранный/подсвечиваемый вопрос (ключ: return/feel/hide/other).
- `picked` — массив выбранных карт (макс 3).
- `tuneStep` (0..2) — активная строка на «Настройке».
- `dealt` — карты розданы; `flips[3]` — какие карты перевёрнуты; `typedArr[3]` — напечатанный текст по каждой; `activeCard` — текущая раскрываемая.
- `showPay` — показать блок покупки; `bought` — идёт «покупка» (спиннер); `cardShake` — тряска финальной карты.
- Таймеры: `_tune` (переходы настройки), `_rd` (последовательность расклада), `_tw` (интервал typewriter), `_qt` (задержка подсветки вопроса). Все чистятся при размонтировании/рестарте.

## Responsive behavior
Две отдельные реализации:
- **Мобильная** (`Таро на него.dc.html`) — вертикальная воронка, ширина ~393–500px, без рамки телефона (полноэкранная колонка).
- **Десктопная** (`Таро на него — ПК.dc.html`) — горизонтальные композиции под ~1200px+ (hero в 2 колонки, сетка вопросов 2×2, ряд карт, 3 колонки толкований, финал в 2 колонки). В узких вьюпортах верстка ужимается; целевая ширина ≥1200px.
