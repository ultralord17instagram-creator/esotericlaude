# Handoff: Таро Терминал — мобильная мини-игра (mobile-first)

## Overview
«Таро Терминал» — короткая гейм-флоу-сессия саморефлексии: пользователь выбирает своё состояние, делает паузу, тянет пиксельную карту Таро, отвечает на 2 вопроса и получает персональный «вывод». Полный разбор скрыт за paywall (7 дней бесплатно, далее подписка). Визуальный язык — «тёплый ретро-CRT-терминал»: сепия/пергамент, пиксельная графика, сканлайны, мягкое свечение, пиксельный заголовочный шрифт.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, созданные в HTML** (`.dc.html`). Это прототипы, показывающие задуманный внешний вид и поведение, **а не продакшн-код для копирования напрямую**. Задача — **воссоздать эти макеты в целевой кодовой базе** её родными паттернами и библиотеками (например Next.js + CSS Modules / Tailwind, React Native и т.п.). Если окружение ещё не выбрано — подобрать наиболее подходящий фреймворк и реализовать дизайн в нём.

`.dc.html` — это внутренний формат прототипа (Design Component). Не пытайтесь запускать их как есть; используйте как визуальный и поведенческий эталон. Открыть можно в браузере, но код надо переписывать под свой стек.

## Fidelity
**High-fidelity (hifi).** Финальные цвета, типографика, отступы, состояния и анимации заданы точно. UI следует воссоздавать пиксель-в-пиксель средствами существующей дизайн-системы кодовой базы. Тексты — плейсхолдеры-примеры на русском, заменяются реальным контентом.

## Общая структура экрана («автомат»)
Каждый экран — это «терминал в корпусе»:
- Внешний **корпус (bezel)**: `linear-gradient(180deg, #8f7647, #5f4e2d)`, `border-radius: 34px` (моб.) / `26px` (десктоп), `padding: 14px` (моб.) / `16px`, тень `inset 0 2px 4px #ffffff33, inset 0 -8px 14px #00000055, 0 12px 26px #00000066`.
- Внутренний **экран**: фон = сканлайны + радиальный градиент пергамента:
  `repeating-linear-gradient(#00000010 0 1px, transparent 1px 3px), radial-gradient(120% 90% at 50% 30%, #e7d6ac, #ddca9c)`;
  `border-radius: 22px`; тень `inset 0 0 60px #4a2f1840, inset 0 0 0 2px #5f4e2d`; `overflow: hidden`.
- Моб. кадр: **320 × 580** (внешний). Десктоп: **920 × 520**, экран в 2 колонки.
- Верхняя **статус-строка** (JetBrains Mono, 9px, letter-spacing 1.5px, `#5c6d40`, text-shadow `0 0 6px #d59a5a`): слева режим (`SELECT MODE`, `QUESTION MODE`, `TERMINAL READS…`), справа статус/шаг.
- Нижняя **primary-кнопка** + мелкая строка `STEP 0X-07`.

## Screens / Views

### 01 · BOOT (стартовый)
- **Purpose**: запуск сессии.
- **Layout**: колонка; центр — крупный пиксельный логотип; низ — кнопка + статус.
- **Компоненты**:
  - Строка `TAROT SYSTEM: ONLINE` (по центру).
  - Логотип «ТАРО / ТЕРМИНАЛ»: Handjet 800, 52px, line-height .86, letter-spacing 1px, цвет `#3c3722`, text-shadow `0 0 14px #d59a5a, 0 0 2px #ffffff88`.
  - Подпись «мини-игра с картой / и вопросами к себе» + мигающий каре́т `▊` цвета `#bd6335` (IBM Plex Mono 12px, `#5f5029`).
  - Primary-кнопка `▶ НАЧАТЬ`.
  - Строка `LEVEL 01 · STEP 00-07 · STATUS: READY`.

### 02 · SELECT (выбор состояния)
- **Purpose**: выбрать 1 из 8 состояний.
- **Layout**: заголовок + вертикальный список из 8 строк-кнопок (gap 8px), низ — счётчик.
- **Компоненты**:
  - Заголовок «ВЫБЕРИ СОСТОЯНИЕ» (Handjet 800, 30px, glow).
  - Строки-состояния (см. компонент «Состояние · меню»): 8 шт. — Тревога, Усталость (выбрана), Гнев, Пустота, Радость, Спокойствие, Растерянность, Надежда.
  - Счётчик `CHOOSE 1 OF 8 · STEP 00-07`.

### 03 · INTRO (введение в состояние)
- **Purpose**: подводка к вытягиванию карты.
- **Компоненты**: прогресс 1/7; лейбл `СОСТОЯНИЕ //`; крупный титул состояния (Handjet 800, 46px); абзац описания (IBM Plex Mono 13px, line-height 1.8); кнопка `Далее ▶`; `STEP 01-07`.

### 04 · PAUSE (пауза/дыхание)
- **Purpose**: короткая практика перед картой.
- **Компоненты**: прогресс 2/7; иконка «пауза» в круге (64px, border 2px `#7c8a56`, glow); заголовок «СДЕЛАЙ ПАУЗУ» (Handjet 800, 34px); инструкция; кнопка `Я готов ▶`; `STEP 02-07`.

### 05 · DRAW (перемешивание/тяга) — С АНИМАЦИЕЙ
- **Purpose**: пользователь тянет карту.
- **Layout**: центр — стопка пиксель-рубашек; ниже подпись; низ — кнопка `Вытянуть ▶`.
- **Ключевое поведение анимации** (см. раздел «Interactions»): колода лежит **одной стопкой на месте**; верхние карты **по очереди** ступенчато приподнимаются и возвращаются — тасуется по одной карте за раз.
- **Пиксель-рубашка**: `aspect-ratio: 350/470`, `border-radius: 2px`, фон = две `repeating-linear-gradient(#00000022 0 6px, transparent 6px 12px)` (гор.+верт., «пиксель-клетка») поверх `linear-gradient(160deg, #5f4e2d, #5c6d40)`; рамка через `box-shadow: inset 0 0 0 3px #d59a5a, inset 0 0 0 6px #5f4e2d, inset -5px -5px 0 #00000044`; в центре пиксельный SVG-«компас/звезда» (crispEdges) цвета `#d59a5a`.

### 06 · REVEAL (карта раскрыта)
- **Purpose**: показать вытянутый аркан.
- **Компоненты**: статус `CARD: REVEAL` + таймер `◷ 10s`; изображение карты (см. Assets), рамка 3px `#d59a5a`, glow `0 0 24px`; подпись аркана (Handjet 700, 22px); строка прогресса + `Пропустить ⏭` (цвет `#bd6335`); кнопка `Далее ▶`; `STEP 04-07`.
- **Flip**: карта прилетает из DRAW и переворачивается (см. Interactions).

### 07 · QUESTION (Q1 и Q2)
- **Purpose**: 2 вопроса с одиночным выбором.
- **Layout**: лейбл «ВОПРОС N / 2 //»; текст вопроса (IBM Plex Mono 600, 17px, line-height 1.45); список из 4 вариантов-чекбоксов (gap 10px); кнопка.
- **Q1**: «Что сейчас забирает больше всего сил?» — варианты: Ожидания других людей / Мои требования к себе (выбран) / Незавершённые дела / Пока не знаю. Кнопка `Далее ▶`, `STEP 05-07`.
- **Q2**: «Что бы стало для тебя облегчением прямо сейчас?» — Разрешить себе не спешить / Попросить о помощи / Отпустить один контроль (выбран) / Тишина хотя бы на час. Кнопка `Узнать вывод ▶`, `STEP 06-07`.
- **Вариант ответа**: см. компонент «Ответ».

### 08 · READING (вывод + закрытый разбор)
- **Purpose**: показать краткий персональный вывод и «дразнилку» закрытого полного разбора.
- **Компоненты**: полный прогресс 7/7; заголовок «ТВОЙ ВЫВОД» (Handjet 800, 28px); открытый абзац-тизер с печатающимся каре́том `▊`; **закрытый блок** (blur+overlay+замок, надпись «РАЗБОР ЗАКРЫТ»); кнопка `Что с этим делать →` цвета `#bd6335`.

### 09 · PAYWALL
- **Purpose**: конверсия в подписку.
- **Компоненты**: `FULL READING · UNLOCK`; заголовок «ОТКРОЙ ПОЛНЫЙ РАЗБОР» (Handjet 800, 30px); список 4 буллетов (✦ `#5c6d40`): Полное значение карты / Что делать с состоянием / Личный вывод и шаг на сегодня / Доступ ко всем 22 картам; **ценовая карточка** «7 ДНЕЙ БЕСПЛАТНО» + «затем 599 ₽/мес · отмена в любой момент»; primary-кнопка `Открыть полный разбор →`; ссылка «пройти заново».

### Desktop-варианты
REVEAL / READING / PAYWALL в 2 колонки, кадр 920×520. Логика та же, крупнее типографика (заголовки Handjet 44–52px, текст 15–16px), карта слева на всю высоту, контент справа.

## Interactions & Behavior

- **Перемешивание (DRAW)** — колода лежит ОДНОЙ стопкой; верхние карты по очереди приподнимаются и возвращаются (тасовка по одной карте).
  - Keyframes `shuffleone`: `0%,5% → translate(0,0) rotate(0)`; `11%,16% → translate(4px,-60px) rotate(-3deg)`; `23% → назад в 0`; до 100% — покой.
  - 4 карты в одной точке (`left:18px; top:38px`), одинаковая анимация `shuffleone 4s steps(5) infinite` со сдвигом задержек `0, -1s, -2s, -3s` → в каждый момент «работает» одна карта. `steps(5)` даёт ступенчатое пиксельное движение.
- **Flip (REVEAL)**: rotateY 0→180° ~600ms; на 90° рубашка меняется на арт; лёгкая вспышка `#d59a5a` в середине.
- **Печать тизера (READING)**: текст набирается по символам (~28ms/символ), мигающий каре́т `▊` цвета `#bd6335` (`@keyframes caret`, 1s step-end).
- **Пульс замка**: `@keyframes lockpulse` scale 1→1.09 + glow, 2.4s ease-in-out infinite.
- **CRT-мерцание**: `@keyframes flick` — едва заметный дроп opacity раз в ~5s на всём экране.
- **Мигающий каре́т BOOT**: `@keyframes blink` 1s step-end.
- **Навигация**: BOOT→SELECT→INTRO→PAUSE→DRAW→REVEAL→Q1→Q2→READING→PAYWALL. «Пропустить ⏭» на REVEAL проскакивает таймер. «пройти заново» с PAYWALL → BOOT/SELECT.

### Reduced motion (`prefers-reduced-motion: reduce`)
Отключить всё: сканлайн-мерцание, тасовку, пульс, печать, каре́т. Стопка карт статична; таймер и текст показываются сразу; переходы мгновенные.

## State Management
- `currentScreen` (enum: boot, select, intro, pause, draw, reveal, q1, q2, reading, paywall).
- `selectedState` (1 из 8 состояний) → влияет на INTRO/тексты.
- `drawnCard` (какой аркан вытянут) → REVEAL/READING.
- `answers` (Q1, Q2) → влияет на текст вывода.
- `step` (0..7) для прогресса/статус-строки.
- `isUnlocked` (подписка) → раскрытие закрытого блока.
- `prefersReducedMotion` (media query).
- Данные: наборы состояний, вопросов, карт (22 аркана), тексты выводов — вероятно с бэкенда/CMS.
