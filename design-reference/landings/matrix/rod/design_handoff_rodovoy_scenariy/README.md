# Handoff: «Родовой сценарий» — лендинг + флоу матрицы судьбы (mobile + desktop)

## Overview
Интерактивный лендинг эзотерического продукта «Родовой сценарий»: пользователь по одной дате рождения получает «матрицу судьбы» с разбором родового сценария по женской линии. Продукт состоит из лендинга и пошагового флоу: вопрос → дата рождения → имя → анимация подсчёта → экран результата (октаграмма + текстовый разбор). Дизайн выполнен в двух версиях — мобильной (в рамке iPhone) и десктопной (1440px).

## About the Design Files
Файлы в этом бандле — **дизайн-референсы, сделанные в HTML** (прототипы, показывающие внешний вид и поведение), а НЕ продакшн-код для прямого копирования. Они написаны как «Design Components» (кастомный формат превью) и опираются на рантайм-обёртку, которой в реальном проекте не будет.

Задача — **воссоздать эти макеты в среде целевого кодовой базы** (React / Vue / Next / SwiftUI / нативка и т.д.) по её сложившимся паттернам и библиотекам. Если среды ещё нет — выбрать подходящий фреймворк (рекомендация: **React + TypeScript**, т.к. вся логика уже написана как React-класс-компонент и переносится 1:1) и реализовать макеты там.

Как читать исходники:
- Разметка каждого экрана лежит в теле `<x-dc>…</x-dc>` — это обычный HTML со **всеми стилями инлайн** (никаких CSS-классов).
- Логика — в блоке `class Component extends DCLogic { … }`: это по сути React.Component без `render()`; `renderVals()` возвращает данные/хендлеры, которые в HTML подставляются через `{{ … }}`.
- Управляющие теги: `<sc-if value>` = условный рендер, `<sc-for list as>` = `.map`, `<dc-import name="X">` = вложенный компонент (файл `X.dc.html`).
- `onClick="{{ fn }}"`, `value="{{ v }}"`, `onChange="{{ fn }}"` — как в React (camelCase).

## Fidelity
**High-fidelity (hifi).** Финальные цвета, типографика, отступы, интерактив и копирайт. Воссоздавать пиксель-в-пиксель средствами библиотек кодовой базы. Единственное исключение — рамка iPhone в мобильной версии: это только обёртка превью, в реальном приложении её не должно быть (мобильный экран = вьюпорт устройства).

## Screens / Views

Флоу управляется одной переменной состояния `screen` со значениями: `landing → quiz → date → name → loading → matrix`. Одинаков для мобильной и десктопной версий; отличается только раскладка.

### 1. Landing (`screen: 'landing'`)
- **Назначение**: объяснить продукт и увести в флоу.
- **Mobile layout**: одна колонка, вертикальный скролл. Секции сверху вниз: hero → «Как это работает» (3 шага списком) → «Что покажет матрица» (список из 4 пунктов на фоне #efe6d9) → отзыв (курсив, Prata) → тёмный финальный CTA (#241a1c) с дисклеймером.
- **Desktop layout (1440px)**: шапка (лого слева + пункты меню + кнопка «Начать» справа). Hero — грид 2 колонки (`1fr 1fr`, gap 72px): слева заголовок+подзаголовок+CTA+строка доверия, справа тёмная карточка-тизер с октаграммой. «Как это работает» — грид 3 колонки, карточки #efe6d9, радиус 22px. «Что покажет» — грид 2 колонки (список слева, карточка-отзыв справа). Финальный CTA — центрированная тёмная секция.
- **Ключевые компоненты**:
  - Прогресс-полоски hero (декоративные): первая активная `#7c2b3b` (46×4px), остальные `rgba(36,26,28,0.14)` (16×3px), скруглof 2px, gap 8px.
  - Заголовок H1: Prata, mobile 33px / desktop 60px, weight 400, line-height 1.12–1.16, `text-wrap: pretty`. Текст: «В твоём роду это повторяется. И круг идёт к тебе.»
  - Подзаголовок: Golos Text, mobile 15.5px / desktop 20px, color `#6b5d5f`. «2 минуты и только дата рождения. Матрица покажет, что ты несёшь по женской линии.»
  - Кнопка CTA: bg `#7c2b3b`, текст `#f7f0ea`, weight 800, radius 18px, тень `0 12px 30px rgba(124,43,59,0.26)`. Текст «Узнать свой родовой сценарий». Клик → `screen: 'quiz'`.
  - Строка доверия: «Анонимно · Без регистрации · 2 минуты», 12–14px, `#a2947f`/`#a08a86`.

### 2. Quiz (`screen: 'quiz'`)
- **Назначение**: первый вопрос (пример шага 1 из 8).
- **Layout**: mobile — колонка, варианты списком (gap 14px); desktop — центрированный блок max-width 760px, варианты в гриде 2×2 (gap 18px).
- **Компоненты**:
  - Хедер шага: кнопка «‹» назад (круг, border `rgba(36,26,28,0.14)`) + сегментированный прогресс из 8 сегментов, первый активен (`#7c2b3b`).
  - Метка «Шаг 1 / 8»: 13px, weight 600, letter-spacing 4px, uppercase, `#a08a86`.
  - Вопрос H1: Prata, mobile 29px / desktop 40px. «Что из этого больше всего похоже на женщин твоего рода?»
  - Варианты (radio-кнопки): кастомный «кружок» слева + текст. Не выбран: bg `rgba(36,26,28,0.03)`, border `rgba(36,26,28,0.1)`, кружок border `#b7a29d`. Выбран: bg `rgba(124,43,59,0.08)`, border `#7c2b3b`, кружок с залитой точкой `#7c2b3b`. transition `border-color .15s, background .15s`, radius 16–18px.
  - Тексты вариантов: «Сильные и одинокие, всё тянули на себе» / «Терпели ради семьи и гасили себя» / «Замужем, но несчастливы, или не сложилось» / «Рано остались без мужчин: развод, вдовство, ушли».
  - Кнопка «Далее»: серая `#c3aca0` пока ничего не выбрано, `#7c2b3b` после выбора. Клик → `screen: 'date'`.

### 3. Date (`screen: 'date'`)
- **Назначение**: ввод даты рождения.
- **Layout**: центрированный блок (mobile max-width экрана, desktop 620px). Прогресс — 8 сегментов, 5 активных.
- **Компоненты**:
  - H1 Prata 28–38px: «Теперь дата рождения, чтобы построить твою матрицу рода».
  - Три `<select>` в ряд (gap 10–14px): **День** (1–31), **Месяц** (названия «Январь»…«Декабрь»), **Год** (2010 → 1940, т.е. 71 значение по убыванию). Высота 62px (mobile) / 72px (desktop), radius 16–18px, border `rgba(36,26,28,0.14)`, bg `rgba(36,26,28,0.03)`, focus border `#7c2b3b`. У «День» и «Год» `appearance: none` + `text-align:center`. Первый `<option>` disabled-плейсхолдер.
  - **Важно**: месяц — это select со списком, НЕ свободный ввод.
  - Кнопка «Далее»: `#c3aca0` пока не выбраны все три поля, `#7c2b3b` когда заполнены. Клик → `screen: 'name'`.

### 4. Name (`screen: 'name'`)
- **Назначение**: ввод имени.
- **Компоненты**: прогресс 7/8; H1 Prata «Как тебя зовут?»; один `<input placeholder="Имя">` (центрированный текст, те же стили полей); кнопка «Построить матрицу рода» (`#7c2b3b`). Клик → запускает loading.

### 5. Loading (`screen: 'loading'`)
- **Назначение**: анимация «подсчёта» с меняющимся текстом.
- **Layout**: полноэкранный тёмный фон `radial-gradient(..., #2a1a1e → #140d0f)`, всё по центру.
- **Компоненты**:
  - Анимированный «оракул»: три вложенных круга — внешний пунктирный вращается (`rsSpin` 7s linear infinite), средний свечение пульсирует (`rsPulse` 1.8s ease-in-out infinite), внутренний сплошной `#c25668`. Mobile ~92px, desktop 130px.
  - Текстовый блок (Prata, mobile 26px / desktop 36px) + подпись (`#b79a95`), появляется с анимацией `rsFade .5s`. `key` привязан к шагу, чтобы анимация повторялась при смене.
  - **Последовательность сообщений** (сменяются каждые 1500ms, `{n}` = имя пользователя):
    1. «Собираю числа твоей даты…» / «Секунду, считаю ядро матрицы»
    2. «Смотрю, что повторяется из поколения в поколение…» / «{n}, круг почти виден…»
    3. «Свожу мужскую и женскую линию рода…» / «Ещё пара секунд»
    4. «Готовлю твой родовой сценарий…» / «{n}, почти всё»
  - После последнего сообщения — пауза 1200ms → `screen: 'matrix'`.

### 6. Matrix / Result (`screen: 'matrix'`)
- **Назначение**: показать матрицу и текстовый разбор.
- **Layout**: mobile — карточка с октаграммой, ниже разбор и 3 блока-вопроса. Desktop — прогресс 8/8, затем грид `520px 1fr` (gap 64px): слева **sticky** тёмная карточка с октаграммой, справа разбор + блоки-вопросы (грид 2 колонки, третий на всю ширину).
- **Компоненты**:
  - **Октаграмма** — см. отдельный раздел ниже (переиспользуемый компонент).
  - Заголовки-рубрики: 13–14px, weight 700, letter-spacing 2.5px, uppercase, `#7c2b3b`.
  - Тело разбора: 16px (mobile) / 19px (desktop), line-height 1.55–1.6, `#3a2c2e`. Тексты — см. файлы.
  - Блоки-вопросы (follow-up): заголовок + пилюля-кнопка «Узнать» (`#7c2b3b`, radius 999px). Тексты: «Почему в вашем роду мужчины не остаются» / «На ком круг замкнётся: на тебе или на дочери» / «Что сделать, чтобы не отдать это дочери».
  - Ссылка «← В начало» → `screen: 'landing'`.

## Октаграмма (матрица судьбы) — ключевой визуал
Отдельный переиспользуемый компонент (`Октаграмма.dc.html`), нарисован **SVG** (viewBox `-34 -14 408 368`, центр 170,170). Используется на десктоп-лендинге (тизер) и на экране результата.
- **Форма**: две наложенные квадратные `<polygon>` образуют 8-конечную звезду (октаграмму). Обводка `#c98a4a` (золото), opacity 0.7, толщина 1.1. Оси и диагонали — пунктирные направляющие (`#c98a4a`, opacity 0.25, dash `2 4`).
- **Узлы** (все круги, текст по центру: `text-anchor=middle` + `dominant-baseline=central`):
  - 4 угловых (r=19): числа 14, 4, 10, 18. Fill `#241a20`, border золото opacity 0.5, текст `#cbb8a0`.
  - 4 кардинальных (r=27): вершины звезды, числа 2 (верх), 2 (право), 16 (низ), 12 (лево). Fill `#241a20`, border `#c98a4a` 2px, текст `#f3ece2`, размер 21px.
  - 4 внутренних (r=18): верх/лево = бирюза `#3f7d74` (7 и 17), право/низ = терракота `#a8582f` (7 и 21). Текст `#f3ece2`/`#f7ece2`.
  - Ядро (r=34): fill радиальный градиент `#2a1c22 → #160f12`, border золото 3px. Крупная «5» (26px, white, weight 800) + подпись «ЛИЧНОСТЬ» (7px, letter-spacing 1.5, `#b79a8f`).
- **Внешние подписи осей** (SVG `<text>`, вынесены за круги, чтобы не перекрываться): «МЕСЯЦ» (верх), «ЗАДАЧА» (низ), «ДЕНЬ» (лево), «ГОД» (право) — `#b39c8b`/`#c9b19d`, 10px. Диагональные «мужская линия» (верх-лево) и «женская линия» (низ-право) — `#d8c4ad`, 9px, повёрнуты `rotate(-45)`.
- **Карточка вокруг октаграммы**: radius 28–32px, фон `radial-gradient(120% 80% at 50% 22%, #34232b 0%, #251a20 62%, #1e1519 100%)`, border `rgba(201,138,74,0.28)`, тень `0 20px 50px` / `0 30px 70px rgba(36,22,28,0.35–0.4)`. Над октаграммой — метка «ТВОЙ РОДОВОЙ СЦЕНАРИЙ» (12.5px, letter-spacing 3.5px, uppercase, `#c2a596`).

Числа в матрице сейчас статичны (мок). В реальной реализации их считает алгоритм «матрицы судьбы» из даты рождения — этот расчёт в дизайне не реализован, нужен на бэкенде/в утилите.

## Interactions & Behavior
- **Навигация**: линейная стейт-машина по `screen`; кнопки «Далее»/«Назад»/«‹» переключают экран. Никакого роутера — просто состояние (в реальном проекте можно завести роуты `/quiz`, `/date`… по желанию).
- **Валидация**:
  - Quiz: кнопка «Далее» активна (меняет цвет `#c3aca0`→`#7c2b3b`) только когда выбран вариант. Сейчас клик проходит всегда — при желании заблокировать до выбора.
  - Date: кнопка активна только когда заполнены все три select.
- **Анимации**: `rsSpin` (вращение, 7s linear), `rsPulse` (масштаб+прозрачность, 1.8s ease-in-out), `rsFade` (появление снизу, .5s ease). Loading автопереключает текст каждые 1500ms и уходит на результат через 1200ms после последнего.
- **Hover/focus**: варианты quiz — transition border/background .15s; поля ввода — border `#7c2b3b` на focus. Ссылки: `#7c2b3b`, hover `#9c4152`.

## State Management
Переменные состояния (React `this.state`):
- `screen`: `'landing' | 'quiz' | 'date' | 'name' | 'loading' | 'matrix'`
- `choice`: `number | null` — индекс выбранного варианта в quiz
- `dd`, `mm`, `yyyy`: строки из select-ов даты
- `name`: строка имени (fallback для отображения — «Алена»)
- `loadStep`: `number` — индекс текущего сообщения на loading

Таймеры: на входе в loading запускается `setInterval` (1500ms), инкрементит `loadStep`; на последнем шаге `clearInterval` + `setTimeout(1200)` → `screen: 'matrix'`. Обязательно очищать таймер при размонтировании.

Данные для select-ов генерируются на лету: дни `1..31`, месяцы — массив названий, годы `2010..1940`.
