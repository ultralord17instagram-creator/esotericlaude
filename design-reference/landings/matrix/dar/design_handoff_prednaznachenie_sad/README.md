# Handoff: Матрица судьбы · «Предназначение» (тема «Сад»)

## Overview
Интерактивный квиз-лендинг по расчёту «матрицы судьбы» по дате рождения. Пользователь проходит короткий флоу, вводит дату рождения и имя, видит анимацию «подсчёта», а затем получает разбор своего предназначения (октаграмма 22 энергий + текстовый разбор + карточки-апселлы). Есть две раскладки одного и того же продукта: **мобильная** и **десктопная (ПК)**.

Тема оформления — **«Сад»**: мягкий велнес-стиль, шалфейно-кремовая палитра, лесной зелёный + глиняный и золотой акценты, серифный заголовочный шрифт Cormorant Garamond + гуманистический гротеск Mulish.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, сделанные в HTML** (прототипы, показывающие внешний вид и поведение), **а не продакшн-код для копирования**. Задача — **воссоздать эти дизайны в целевой кодовой базе** её принятыми средствами (React / Vue / Next / SwiftUI / нативно и т.д.), используя существующие в проекте паттерны, компоненты и библиотеки. Если окружения ещё нет — выбрать наиболее подходящий фреймворк и реализовать дизайн в нём.

Файлы `.dc.html` — это самодостаточные HTML-страницы (открываются в браузере). Они используют небольшой рантайм-шаблонизатор (`support.js`, включён в пакет только чтобы прототип открывался). **В рантайме `support.js` нет необходимости** — это деталь среды прототипирования, не переносите её в продакшн. Ориентируйтесь на разметку, стили и описанное ниже поведение.

> ⚠️ Важная деталь среды прототипа: переход с экрана «загрузка» на экран «результат» сделан **по клику на кнопку «Показать мой разбор»**, потому что в песочнице прототипа перерисовку надёжно вызывает только клик. **В нормальном фронтенде делайте автопереход по таймеру** (например, `setTimeout` на ~5.2 c) — кнопку можно оставить как «пропустить» или убрать. Это ограничение прототипа, а не требование продукта.

## Fidelity
**High-fidelity (hi-fi).** Финальные цвета, типографика, отступы, скругления и тексты. Воссоздавайте UI пиксель-в-пиксель средствами кодовой базы. Обе раскладки (мобайл и ПК) — это один продукт: в реальной реализации это, скорее всего, **один адаптивный компонент-флоу** с брейкпоинтом (мобильная раскладка — колонка в «телефоне»; ПК — широкие секции 1440px). Мобильный прототип нарисован внутри рамки-«телефона» (корпус/вырез) — **рамка нужна только для превью, не переносите её**, берите содержимое экрана.

## Screens / Views
Флоу состоит из 6 экранов-состояний, переключаемых одной стейт-переменной `screen`:
`landing → quiz → date → name → loading → matrix`.

### 1. Landing (лендинг)
- **Purpose**: объяснить оффер и запустить квиз.
- **Мобайл layout**: вертикальная прокрутка, секции сверху вниз: шапка (лого + подпись), герой (заголовок по центру + подзаголовок + CTA), «Как это работает» (3 шага с круглыми номерами), «Что покажет матрица» (список из 4 пунктов, буллеты-глина), отзыв (курсив, Cormorant), финальный CTA-блок на тёмно-зелёном фоне + дисклеймер.
- **ПК layout**: шапка с навигацией и кнопкой «Начать» (72px гориз. паддинги); герой — grid 2 колонки (слева текст с крупным заголовком 66px, справа тёмно-зелёная карточка 470px с октаграммой); «Три шага» — grid 3 колонки, карточки `#eef0e0` радиус 24; «Что покажет» — grid 2 колонки на фоне `#e7ecda` (слева заголовок+список, справа карточка-отзыв); финальный CTA — секция на тёмно-зелёном радиальном градиенте по центру.
- **Ключевые копирайты**:
  - Заголовок: «Твоё предназначение уже вписано в дату рождения.»
  - Подзаголовок: «2 минуты и только дата рождения. Матрица покажет, зачем ты здесь и в чём твоя настоящая сила.»
  - CTA: «Узнать своё предназначение»
  - Финальный заголовок: «Готова узнать, зачем ты здесь?»
  - Дисклеймер: «Матрица судьбы — инструмент саморефлексии, а не медицинская или психологическая услуга.»

### 2. Quiz (вопрос)
- **Purpose**: один вопрос с одиночным выбором (задел под многошаговый квиз, прогресс размечен как «Шаг 1 / 8»).
- **Layout**: назад-кнопка (круглая) + прогресс-бар; надзаголовок «Шаг 1 / 8»; заголовок «Что из этого тебе сейчас ближе всего?»; варианты (мобайл — колонка; ПК — grid 2×2); кнопка «Далее».
- **Варианты** (радио, один выбор): «Чувствую, что занимаюсь не своим делом» · «Ищу себя и не понимаю, куда идти» · «Много всего умею, но не вижу главного» · «Есть силы, но нет ясности и смысла».
- **Поведение**: пока вариант не выбран — кнопка «Далее» неактивного цвета `#b7c0a6`; после выбора — зелёная `#4a6b4e`. (В прототипе клик по «Далее» ведёт дальше даже без выбора; в проде можно блокировать до выбора.)

### 3. Date (дата рождения)
- **Purpose**: ввод даты рождения тремя селектами (День / Месяц / Год).
- **Layout**: прогресс ~62%; заголовок «Теперь дата рождения, чтобы построить твою матрицу судьбы»; ряд из трёх `<select>` (день 1–31, месяц названиями, год 2010→1940); кнопка «Далее».
- **Поведение**: кнопка «Далее» серо-зелёная, пока не заполнены все три поля, затем зелёная.

### 4. Name (имя)
- **Purpose**: ввод имени (используется в текстах загрузки и в заголовке разбора).
- **Layout**: прогресс ~87%; заголовок «Как тебя зовут?»; текстовое поле (плейсхолдер «Имя»); кнопка «Построить матрицу судьбы».
- **Поведение**: если имя пустое — в разборе используется дефолт «Алена» (в проде — попросить имя или подставлять нейтральное).

### 5. Loading (анимация подсчёта)
- **Purpose**: имитация расчёта, удержание внимания ~5 секунд.
- **Layout**: тёмно-зелёный радиальный фон; крупный «планетарный» индикатор (пунктирное вращающееся кольцо + пульсирующее золотое ядро); под ним по очереди сменяются 4 сообщения; затем появляется кнопка перехода.
- **4 сообщения** (title / подпись), сменяются примерно по ~1.3 c:
  1. «Собираю числа твоей даты…» / «Секунду, считаю ядро матрицы»
  2. «Раскладываю 22 энергии предназначения…» / «{Имя}, картина проявляется…»
  3. «Свожу таланты и задачу души…» / «Ещё пара секунд»
  4. «Готовлю твой разбор предназначения…» / «{Имя}, почти всё»
- **Переход к результату**: см. примечание выше — **в проде автопереход по таймеру ~5.2 c**.

### 6. Matrix (результат)
- **Purpose**: показать «матрицу» (октаграмму) и разбор предназначения + апселлы.
- **Мобайл layout**: карточка с октаграммой (тёмно-зелёный градиент) → надзаголовок «Разбор для {Имя}» (в мобайле опущен заголовок, сразу секции) → секция «Зачем ты пришла в этот мир» (лейбл + абзац) → «Что мешает тебе жить этим» (лейбл + абзац) → 3 карточки-апселла (вопрос + кнопка «Узнать») → ссылка «← В начало».
- **ПК layout**: grid 2 колонки: слева **sticky** карточка с октаграммой (тёмно-зелёный градиент, ширина 520px), справа — надзаголовок «Разбор для {Имя}», заголовок «В чём твоё предназначение» (Cormorant 52px), две текстовые секции, grid карточек-апселлов (2 в ряд + 1 на всю ширину), ссылка «← В начало».
- **Октаграмма**: SVG из двух наложенных квадратов (образуют 8-конечную звезду) + оси НЕБО/ЗЕМЛЯ/РОД/ДАР, диагонали «душа»/«миссия», угловые и боковые узлы с числами и центральное «ЯДРО = 10». Значения чисел в прототипе — **демо-данные, не рассчитанные**. В проде числа должны считаться из даты рождения (см. State ниже).
- **Тексты разбора** — демонстрационные (см. в файлах), в проде генерируются/подбираются по числам матрицы.

## Interactions & Behavior
- **Навигация**: одна стейт-переменная `screen`. Кнопки переключают её. Стрелки «назад» на quiz/date/name возвращают на предыдущий экран.
- **Выбор варианта** в quiz: `choice` (индекс) → подсветка выбранного (рамка `#4a6b4e`, фон `rgba(74,107,78,0.1)`, заполненная радио-точка).
- **Валидация даты**: кнопка активна, когда заполнены день+месяц+год.
- **Анимация загрузки**: длительность ~5.2 c, 4 сообщения по ~1.3 c (crossfade opacity), затем автопереход к matrix (в проде — таймером). Индикатор: вращение кольца 8 c linear infinite, пульс ядра 1.9 c ease-in-out infinite.
- **Появление сообщений/кнопки**: плавное (opacity/translateY), ease.
- **Ховеры**: ссылки — из палитры (`a` → `#4a6b4e`, hover `#3a5640`). Для кнопок в проде добавьте лёгкий hover (затемнение/приподнятие) в стиле кодовой базы.

## State Management
Нужные переменные состояния:
- `screen`: `'landing' | 'quiz' | 'date' | 'name' | 'loading' | 'matrix'`
- `choice`: `number | null` — выбранный вариант квиза
- `dd`, `mm`, `yyyy`: строки даты рождения
- `name`: строка имени
- (в проде) `matrix`: результат расчёта — массив/объект чисел для узлов октаграммы + подобранные тексты разбора

Переходы: `landing→quiz` (CTA) → `quiz→date` (Далее) → `date→name` (Далее) → `name→loading` (Построить) → `loading→matrix` (по таймеру) → `matrix→landing` (В начало). Стрелки назад — обратные переходы.

Data fetching: в прототипе данных нет. В проде: (1) алгоритм расчёта матрицы судьбы из даты рождения (нумерология 22 арканов — сумма/редукция чисел даты по узлам), (2) сопоставление чисел с текстами разбора (из контента/CMS или генерации).

### Типографика
- Заголовки: **Cormorant Garamond**, weight 500–600 (герой ПК 66px, заголовки экранов 44–52px ПК / 28–32px мобайл, отзыв — italic).
- Текст/интерфейс: **Mulish**, 400–700 (body 15–20px, лейблы 12–14px uppercase с letter-spacing 2–2.5px).
- Числа в SVG: Mulish 700.

### Скругления
- Кнопки: pill `999px`.
- Поля/селекты: 12–18px.
- Карточки: 18–28px.
- Карточка октаграммы: 26–30px.

### Тени
- CTA зелёный: `0 12–16px 26–34px rgba(74,107,78,0.3)`
- CTA золото: `0 14–16px 30–34px rgba(203,180,106,0.24–0.3)`
- Карточка октаграммы (тёмная): `0 20–30px 50–70px rgba(45,60,45,0.4)`

### Отступы (ориентиры)
- ПК: гориз. паддинг секций 72px, вертикальные 96–104px.
- Мобайл: гориз. 26px, экран телефона 360×780 внутри корпуса 384px.
- Прогресс-бары: высота 6–8px, радиус 3–4px.

## Assets
Внешних изображений нет. Единственная графика — **октаграмма, нарисованная инлайновым SVG** (две `polygon`-звезды, линии-оси, `circle`+`text` узлы). Иконок-ассетов нет; стрелки/«‹» — текстовые глифы. Шрифты — Google Fonts (Cormorant Garamond, Mulish). Если в кодовой базе есть свои шрифты/иконки — используйте их, сохранив характер (серифный заголовок + чистый гротеск).
